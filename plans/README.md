# Public Workflow Plans

These synthetic plans demonstrate how to describe the same sample workflows in English and Korean. English is the primary public format; Korean counterparts are included for localization comparison.

| Sample | English plan | Korean plan |
| --- | --- | --- |
| Standard HTML inventory inquiry | [standard-html-inventory.en.md](standard-html-inventory.en.md) | [standard-html-inventory.ko.md](standard-html-inventory.ko.md) |
| React purchase order | [react-purchase-order.en.md](react-purchase-order.en.md) | [react-purchase-order.ko.md](react-purchase-order.ko.md) |

The plans intentionally contain no login or screen-navigation section because the sample URL opens the target screen directly. Each plan separates inputs, workflow steps, judgment rules, completion evidence, and stop/report conditions.

All values are synthetic and safe for public testing.
