# 표준 HTML 재고조회 및 행 추가

## 목적

표준 HTML 샘플에서 재고를 조회하고 의미 기반 팝업으로 품목을 선택한 뒤 결과 행을 한 개 추가한다.

## 시작 조건

- 표준 HTML 샘플이 `/samples/standard-controls.html`에서 열려 있다.
- 화면 언어가 한국어로 선택되어 있다.
- 로그인과 메뉴 진입은 필요하지 않다.

## 입력 정보

- 창고: 서울창고
- 품번/품명: ITEM-001
- 품목구분: 원자재
- 기준일: 2026-08-04
- 재고 상태: 가용재고
- 0 재고 포함: 선택 안 함

## 업무 절차

1. 창고 컨트롤에서 서울창고를 선택한다.
2. 품번/품명 옆 검색 버튼으로 품목 검색 팝업을 연다.
3. 팝업의 품번/품명에 `ITEM-001`을 입력한다.
4. 팝업 내부의 조회 버튼을 누른다.
5. 정확히 일치하는 `ITEM-001` 결과를 선택한다.
6. 확인 버튼을 누르고 팝업이 닫혔는지 확인한다.
7. 본 화면의 품번/품명에 `ITEM-001`이 반영됐는지 확인한다.
8. 품목구분에서 원자재를 선택한다.
9. 기준일을 입력한다.
10. 재고 상태에서 가용재고를 선택하고 0 재고 포함은 선택하지 않는다.
11. 본 화면의 조회 버튼을 누른다.
12. 결과 테이블에 `ITEM-001`이 있는지 확인한다.
13. 현재 결과 행 개수를 기록한다.
14. 행 추가 버튼을 한 번 누른다.
15. 결과 테이블의 행 개수가 정확히 한 개 증가했는지 확인한다.

## 판단 규칙

- 좌표보다 label, 접근성 role, 안정적인 ID 또는 test ID를 먼저 사용한다.
- 활성 팝업 범위를 기준으로 팝업 조회와 본 화면 조회를 구분한다.
- 클릭 성공만으로 완료하지 않고 실제 상태 변화를 확인한다.
- 안정화된 빈 결과는 정상적인 0건 조회로 판단한다.
- 저장 버튼은 누르지 않는다.

## 완료 조건

- 품목 검색 팝업이 정상적으로 열리고 닫혔다.
- 본 화면의 품번/품명에 `ITEM-001`이 유지된다.
- 본 화면 조회 결과가 안정화됐다.
- 행 추가 후 대상 결과 테이블의 행 개수가 정확히 한 개 증가했다.

## 중단·보고 조건

- 대상 컨트롤을 명확하게 식별할 수 없다.
- 검색 후 팝업이 표시되지 않는다.
- 선택한 품목이 본 화면에 반영되지 않는다.
- 결과 행 개수가 정확히 한 개 증가하지 않는다.
- 외부 데이터 전송이나 파괴적 동작이 필요하다.
