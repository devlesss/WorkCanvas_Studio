# React 구매발주 및 상세 1행 입력

## 목적

React 샘플에서 구매발주 마스터 정보를 입력하고 팝업으로 협력사를 선택한 뒤 상세 행 한 개를 추가한다.

## 시작 조건

- React 샘플이 `/samples/react/`에서 열려 있다.
- 화면 언어가 한국어로 선택되어 있다.
- 로그인과 메뉴 진입은 필요하지 않다.

## 입력 정보

- 발주일: 2026-08-04
- 계정구분: 원자재
- 협력사: 원진
- 조달유형: 매입(국내)
- 비고: 공개 워크플로 샘플
- 품목: PART-001
- 수량: 10
- 긴급: 선택 안 함

## 업무 절차

1. 발주일을 입력한다.
2. 계정구분에서 원자재를 선택한다.
3. 협력사 옆 검색 버튼을 누르고 협력사 검색 팝업이 표시되는지 확인한다.
4. 거래처코드/명에 `원진`을 입력한다.
5. 팝업 내부의 조회 버튼을 누른다.
6. 정확히 일치하는 `V001 · 원진` 결과를 선택한다.
7. 확인 버튼을 누르고 팝업이 닫혔는지 확인한다.
8. 읽기 전용 협력사 필드에 원진이 반영됐는지 확인한다.
9. 조달유형에서 매입(국내)을 선택한다.
10. 비고에 `공개 워크플로 샘플`을 입력하고 React 상태에 값이 유지되는지 확인한다.
11. 발주상세의 현재 행 개수를 기록한다.
12. 행 추가 버튼을 한 번 누른다.
13. 발주상세 행 개수가 정확히 한 개 증가했는지 확인한다.
14. 새 행의 품목에서 `PART-001 · 모터 어셈블리`를 선택한다.
15. 수량에 `10`을 입력하고 긴급은 선택하지 않는다.
16. 같은 새 행의 품목, 수량, 긴급 상태를 검증한다.

## 판단 규칙

- 생성된 프레임워크 경로보다 label, 접근성 role, 안정적인 ID와 test ID를 우선한다.
- 팝업 컨트롤은 표시된 `role="dialog"` 범위 안에서 찾는다.
- React controlled state가 갱신되도록 정상적인 input/change 이벤트를 사용한다.
- 상세 입력은 현재 행 추가 동작으로 생성된 새 행에 고정한다.
- 저장 버튼은 누르지 않는다.

## 완료 조건

- 협력사 검색 팝업이 정상적으로 열리고 닫혔다.
- 협력사 필드에 원진이 유지된다.
- 비고 값이 React 상태 갱신 후에도 유지된다.
- 상세 행이 정확히 한 개 추가됐다.
- 새 행에 PART-001, 수량 10, 긴급 선택 안 함이 유지된다.

## 중단·보고 조건

- controlled input이 요청 값을 유지하지 못한다.
- 협력사 검색 팝업이 표시되지 않는다.
- 선택한 협력사가 본 화면에 반영되지 않는다.
- 새 상세 행을 명확하게 식별할 수 없다.
- 외부 데이터 전송이나 파괴적 동작이 필요하다.
